# FRM lookup

Answer FRM questions from the course knowledge base, not from memory alone.

## Where the data is

- Graph index: `${CLAUDE_SKILL_DIR}/../../graph/concept-graph.json`
- Full entries: `${CLAUDE_SKILL_DIR}/../../semantic-layer/`
  - `terminology/<part>/<reading>.yaml` holds terms: `definition`, `aliases`, `acronyms`, `notation`, `examples`
  - `concepts/<part>/<reading>.yaml` holds concepts
  - `formulas/<part>/<reading>.yaml` holds formulas: `latex`, `variables`, `assumptions`, `conventions`, `variants`, `examples`
  - `notation.yaml` holds shared symbol definitions

## Steps

1. **Find the entry.** Search `concept-graph.json` for the term. Match on the `id` (kebab-case, e.g. `market-risk`), on `name`, or on `aliases` (which include acronyms), ignoring case. Use Grep on that file rather than reading all of it once it grows.
2. **Read the full entry.** The node's `file` field gives the YAML file. Open it and find the entry with that `id`. The YAML has fields the graph leaves out (variables, assumptions, examples).
3. **Answer.**
   - Give the definition or formula from the entry. Render formulas from `latex`, explain each variable, and state the assumptions.
   - If the entry has `examples` with `inputs` and `output`, walk through one. Check that the arithmetic reproduces `output` within `tolerance`.
   - Cite `source` when it is filled in, e.g. "(GARP FRM Part I, Book 4, ch. 3)".
   - Mention one to three linked entries from the node's `links` when they help, e.g. a formula's `uses-concept` link or the sub-types of a risk.
4. **Say when the notes don't cover it.** If there is no match, or the node's `kind` is `missing` or `complete` is `false`, tell the user their notes don't define it yet. You can then answer from general knowledge, but label it clearly as not from the course materials, and suggest which reading file it belongs in.

## Rules

- Never present general knowledge as if it came from the notes.
- Field values of `null` mean "not filled in yet".
- Don't edit the YAML or the `graph/` files unless the user asks. The graph files are generated by `scripts/build_graph.py`.
